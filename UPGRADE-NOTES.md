# Personal portfolio upgrade

This change builds on the existing site rather than replacing its content or approved XPS artwork. It adds a homepage directory, responsive standalone navigation, publication filters, music search and transport, structured data and page-specific sharing previews. It preserves the original 17 audio files, project URLs, CV printing, and original page anchors.

The existing Max Planck affiliation and standard CV employment timeline are retained. No new research results, institutional endorsements, software availability or publication authorships are asserted. The CV is printable using the existing Print or save as PDF control.
