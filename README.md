## Development

Serve the repository root with `python3 -m http.server 8000`. Run browser tests with Node.js 22, `npm install --no-save @playwright/test@1.58.2`, `npx playwright install chromium`, and `npx playwright test tests/website.spec.cjs`. GitHub Actions runs tests on pull requests and pushes to main.
